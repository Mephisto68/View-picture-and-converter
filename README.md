# View Picture and Converter          ![GitHub](https://img.shields.io/github/license/Mephisto68/View-picture-and-converter) ![GitHub stars](https://img.shields.io/github/stars/Mephisto68/View-picture-and-converter?style=social)

Voir les images d'un dossier (et sous dossier) et pouvoir les convertir

### Formats supportés :
- PNG
- JPG
- WEBP
- BMP
- ICO
- SVG
- PDF

## Comment utiliser
1. Sélectionnez un dossier contenant vos images.
2. Accepter l'import
3. Accepter ou annuler l'import des sous-dossier
4. Cliquez sur une image
5. Choisissez le format de sortie souhaité.
6. Cliquez sur "Ok".
